# Hooks

Hooks are officially documented and make Claude Code feel much more like an automation runtime than a plain chat tool.

Anthropic documents hook events including:

- `PreToolUse`
- `PostToolUse`
- `Notification`
- `UserPromptSubmit`
- `Stop`
- `SubagentStop`
- `PreCompact`
- `SessionStart`
- `SessionEnd`
